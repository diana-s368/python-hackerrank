# Homework 1: Python Exercises

This repository contains materials for **Homework 1** in the Algorithms for Data Mining course at Sapienza University of Rome.

## Contents

- [`homework1.ipynb`](homework1.ipynb) — A Jupyter notebook with Python solutions and notes for introductory programming exercises, primarily drawn from HackerRank's Python practice track. Topics include:
  - Basic input, conditionals, arithmetic, loops, and functions
  - Lists, tuples, nested lists, and dictionaries
  - String operations and formatting
  - Sets and set operations
  - Collections such as `Counter`, `defaultdict`, and `namedtuple`
  - Calendar and date handling, exceptions, and score aggregation
  - Lambda functions, Fibonacci numbers, regular expressions, and parsing
- [`homework1.pdf`](homework1.pdf) — The homework assignment document.

## Working with the notebook

Open `homework1.ipynb` in Jupyter Notebook, JupyterLab, or another compatible notebook viewer. Many exercises contain both input-based solutions and example values; run cells in order and provide input where prompted.

## Source

The notebook identifies HackerRank's Python practice track as its exercise source: [HackerRank](https://www.hackerrank.com/dashboard).
